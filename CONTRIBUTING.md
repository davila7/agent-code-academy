# Contributing

Thank you for helping improve Agent Code Academy.

## Ways to contribute

- Add or correct a technical learning resource.
- Improve search, accessibility, performance, or responsive behavior.
- Report broken links or inaccurate catalog metadata.
- Improve documentation and contributor tooling.

## Development workflow

1. Fork the repository and create a focused branch from `main`.
2. Install dependencies with `npm ci`.
3. Make the smallest change that solves the issue.
4. Run `npm run check`.
5. Open a pull request describing the motivation and verification performed.

## Catalog quality rules

- Prefer official, first-party, or clearly authoritative sources.
- Resources must teach a technical workflow; avoid thin promotional pages.
- Summaries must be original, neutral, and concise.
- Do not add referral parameters or affiliate links.
- Keep IDs stable after publication.
- Mention trademarks accurately and avoid implying endorsement.

## Pull requests

Keep pull requests scoped and reviewable. Screenshots are useful for visible UI
changes. By contributing, you agree that your contribution is licensed under
the project's MIT License.
